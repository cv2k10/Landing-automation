## Reel 1: Which hosting should you choose?

Your client's website is finished... but where should it LIVE? 🏠☁️

Picking the wrong hosting means slow pages, surprise bills, or late-night server fixes. Here are the 5 main options in about a minute:

🏘️ Shared hosting: cheap and easy, great for small WordPress sites. The catch: you share one server with hundreds of neighbors.
⚡ Static hosting (Netlify, Vercel, GitHub Pages): often free and super fast. Perfect for landing pages and portfolios, but no PHP or database built in.
🔑 VPS: your own private virtual server with full control. Ideal for Laravel or custom apps, but updates, security and backups are on you.
🛡️ Managed WordPress: costs more, but experts handle speed, backups and security.
☁️ Cloud (AWS, Google Cloud): scales to millions of visitors, but it's complex to set up.

✅ Quick guide:
Landing page → Static
Small business WordPress → Shared or Managed
Custom app → VPS
Huge traffic → Cloud

Match the hosting to the project, not the hype. 💡

## Reel 2: What's GitHub & a repository?

Ever broken a website and wished you could just hit UNDO? ⏪ That's exactly what GitHub is for.

If you build websites for clients, version control is your safety net. Here's what it does for you:

📸 Commit: Git saves a snapshot of your code every time you make a change
🕒 History: see who changed what, and when
📁 Repository (repo): your project folder plus its whole history, kept safe on GitHub
💾 Backup: laptop died? Your code is still on GitHub
⏪ Recover: pushed a bug to the live site? Roll back to yesterday's working version
💻 Clone: copy the whole project to any computer with one command
🌿 Feature branch: try new features without touching the live site
🤝 Pull request: teammates review and comment, then merge into main

Commit. Push. Branch. Merge. Learn GitHub once, and every client project gets safer. 🔒
